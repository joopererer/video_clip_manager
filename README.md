# Video Clip Manager

一个基于 Flutter 开发的视频片段管理器，专注于"软截取"和智能收藏管理。

## 软件设计理念

### 为什么开发这个应用？

在观看视频时，我们经常会遇到这样的情况：
- 一个长视频中只有几个片段是精华内容
- 想要收藏这些片段，但不想破坏原视频文件
- 希望能够将这些片段串联起来，形成连续的播放体验
- 避免传统视频编辑软件的复杂性和文件损失

### 核心设计理念

#### 1. **软截取 (Soft Clipping)**
- **不破坏原文件**：通过时间标记来"虚拟截取"片段，原视频文件保持完整
- **零质量损失**：避免重新编码导致的分辨率损失
- **快速处理**：无需等待视频重新渲染，即时创建片段

#### 2. **智能收藏管理**
- **精确时间控制**：毫秒级的开始和结束时间设置
- **标签系统**：通过颜色编码的标签进行智能分类
- **评分系统**：1-5星评分和收藏功能
- **搜索过滤**：多维度搜索和过滤功能

#### 3. **播放列表系统**
- **片段串联**：将多个片段组合成播放列表
- **连续播放**：无缝切换，模拟完整视频体验
- **轨道视图**：可视化时间轴，参考专业视频编辑软件设计
- **拖拽排序**：直观的片段重排序功能

#### 4. **用户体验优先**
- **简洁界面**：专注于核心功能，避免复杂操作
- **即时反馈**：所有操作都有即时的视觉反馈
- **数据持久化**：自动保存所有设置和状态
- **跨平台支持**：Windows 桌面应用，未来可扩展到其他平台

### 开发过程中的重要决策

#### 1. **移除"编辑时间"功能**
经过深入讨论，决定移除播放列表中的"编辑时间"功能，因为：
- 违背了"软截取"的设计理念
- 造成功能重复（已有 clip_editor_screen）
- 增加不必要的复杂度
- 可能导致数据一致性问题

#### 2. **编辑模式 + 备份状态模式**
为了解决播放列表管理中的状态同步问题，实现了：
- 本地编辑状态与全局状态的分离
- 只有保存时才同步到全局状态
- 重置功能可以完美恢复到原始状态
- 避免了复杂的状态同步逻辑

#### 3. **UI/UX 设计原则**
- **一致性**：所有标签页保持统一的设计风格
- **简洁性**：移除冗余功能，专注于核心需求
- **直观性**：拖拽排序、颜色编码等直观操作
- **响应性**：所有操作都有即时反馈

### 增强的片段播放屏幕
片段播放屏幕已完全重新设计，具有高级功能：

#### 播放控制
- **重播按钮**：立即从开头重新开始片段
- **播放/暂停切换**：通过视频上的覆盖控制来控制播放

#### 交互功能
- **星级评分系统**：直接从播放器中点击星星来评分片段

- **上一个/下一个按钮**：在集合中的片段之间导航
- **无缝过渡**：无需关闭播放器即可在片段之间切换
- **视觉反馈**：当没有上一个/下一个片段时禁用按钮

#### 信息显示
- **时间范围**：显示开始时间、结束时间和总时长
- **标签和注释**：显示片段元数据（可用时），带有彩色标签芯片
- **视频文件**：显示源视频文件名
- **增强布局**：更大的窗口（720x680）以获得更好的观看体验

#### 技术功能
- **状态管理**：评分和收藏的实时更新
- **响应式设计**：适应不同的屏幕尺寸
- **内存效率**：正确清理视频资源
- **错误处理**：优雅处理缺失文件或导航错误

#### 排序和统计
- **高级排序**：8种不同的排序选项，包括：
  - 名称（A-Z / Z-A）
  - 添加日期（最新 / 最早）
  - 评分（高到低 / 低到高）
  - 时长（长到短 / 短到长）
- **实时统计**：显示过滤计数与总计数（例如，"15 / 25"）
- **智能默认**：默认按最新片段排序
- **即时排序**：更改排序选项时结果立即更新
- **美观的UI**：具有渐变、阴影和平滑动画的现代设计

#### 列表视图
- **星级评分系统**：点击星星来评分片段（1-5星，再次点击移除评分）
- **收藏系统**：心形图标来标记/取消标记片段为收藏
- **增强信息显示**：显示开始时间、结束时间、时长和标签
- **标签颜色编码**：每个标签根据其内容显示独特的、一致的颜色
- **直接编辑**：点击编辑按钮打开片段编辑器
- **快速操作**：每个片段的播放、编辑和删除按钮

#### 网格视图
- **紧凑卡片布局**：带有缩略图的可视卡片
- **交互控制**：
  - 带有可点击星星的星级评分系统
  - 带有心形图标的收藏切换
  - 快速预览的播放按钮
  - 标题中的编辑和删除按钮
- **视觉指示器**：收藏片段在标题中显示心形图标
- **时长显示**：以等宽字体显示片段时长
- **响应式设计**：根据屏幕宽度调整网格大小
