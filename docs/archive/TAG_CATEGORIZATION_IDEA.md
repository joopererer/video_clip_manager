# Tag 智能分类功能设计思考

## 背景
用户反馈tag排序功能不够实用，希望考虑如何根据tag进行分类，实现虚拟智能目录功能。

## 当前Tag系统分析

### 现有功能
- 标签筛选：支持多标签组合筛选
- 标签显示：在clip信息中显示标签
- 标签管理：在clip编辑器中添加/删除标签

### 局限性
- 标签排序不够实用（已移除）
- 缺乏标签的层次结构
- 没有标签的智能分组功能

### 2. 智能分类算法

#### 自动分类规则
1. **时间分类**：根据视频文件名或元数据自动识别年份
2. **类型分类**：基于常见视频类型关键词
3. **评分分类**：根据星级自动分组
4. **时长分类**：按视频时长范围分组
5. **收藏分类**：根据收藏状态分组

#### 用户自定义分类
1. **标签组合**：用户可以创建标签组合规则
2. **智能标签**：基于现有标签自动生成新标签
3. **批量操作**：支持批量添加/修改标签

### 4. 技术实现方案

#### 数据结构
```dart
class TagCategory {
  final String name;
  final String icon;
  final List<String> tags;
  final int count;
  final TagCategoryType type;
}

enum TagCategoryType {
  auto,      // 自动分类
  custom,    // 用户自定义
  smart      // 智能分类
}
```

#### 分类逻辑
```dart
class TagCategorizationService {
  // 自动分类
  List<TagCategory> generateAutoCategories(List<VideoClip> clips);
  
  // 智能分类
  List<TagCategory> generateSmartCategories(List<VideoClip> clips);
  
  // 用户自定义分类
  List<TagCategory> getUserCategories();
}
```

### 5. 用户体验优化

#### 渐进式功能
1. **第一阶段**：基础分类视图（时间、评分、收藏）
2. **第二阶段**：智能标签建议
3. **第三阶段**：用户自定义分类规则
4. **第四阶段**：高级分类算法

#### 交互设计
- **快速切换**：在列表视图和分类视图间快速切换
- **智能建议**：基于用户行为推荐分类
- **批量操作**：支持批量标签管理
- **搜索集成**：分类结果支持搜索和筛选

### 6. 实现优先级

#### 高优先级
1. ✅ 移除tag排序功能（已完成）
2. 🔄 优化排序UI设计（已完成）
3. 📋 添加基础分类视图（时间、评分、收藏）

#### 中优先级
1. 🏷️ 智能标签建议系统
2. 📊 分类统计和可视化
3. 🔍 分类内搜索功能

#### 低优先级
1. ⚙️ 用户自定义分类规则
2. 🤖 高级AI分类算法
3. 📱 分类视图的移动端优化

## 总结

通过实现智能分类功能，可以：
- 提供更直观的视频组织方式
- 减少用户手动分类的工作量
- 提升视频发现和浏览体验
- 为未来的高级功能奠定基础

建议先从基础分类视图开始，逐步完善智能分类功能。
