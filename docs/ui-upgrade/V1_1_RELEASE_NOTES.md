# Video Clip Manager v1.1.0 — Release Notes

发布日期：待定（本地已准备就绪，尚未推送 / 发布）
构建版本：`1.1.0+3`（`pubspec.yaml` → Windows 版本资源，EXE 属性与「关于」同源）
Windows 包：`video_clip_manager-v1.1.0-windows-x64.zip`

## 本次亮点

### 深色工作区：整窗重生

- 全新响应式 Shell：208 px / 64 px 可折叠侧栏、60 px 顶栏与可伸缩内容区，三页导航（片段库 / 原始视频 / 播放列表）在窄窗口下自动收拢次级功能而不挤压内容。
- 片段库支持**网格 / 列表**两种视图，卡片统一了悬停、键盘焦点、选中边框与右键菜单的行为差异，长标签与竖屏媒体的留边不再错位。
- 空状态、缺失源文件、加载中都有明确落点，不再出现"点了没反应"的空白页。

### 原始视频预览：双击就是看片，不再误入剪辑器

- 「原始视频」页的单双击语义彻底分开：双击 / 播放按钮 / 右键「播放」打开**预览对话框**；剪刀按钮 / 右键「创建片段」直接进剪辑器。
- 预览内有播放暂停、可拖动进度条（`位置 / 总时长`）、静音与音量还原、全屏、一键「创建片段」；`Esc` 关闭，全屏时先退出全屏。
- 表头同时给出片源类型（本地文件 / 网络串流 / 在线平台）、时长、分辨率（竖屏会标注 `portrait`）与片段数量。

### 播放列表体验

- 播放列表工作台支持编排、连播与跨片段跳转，M3U8 在线源在片段库与播放列表里都能正常打开（修复了此前"文件不存在"的误报）。
- 播放器与剪辑器都补齐了**音量滑杆与静音切换**，取消静音时恢复静音前的音量，而不是拍回 100%。

### AI 语义搜索：看得见分数，也排得出顺序

- 搜索结果直接在缩略图 / 列表行上显示**真实余弦相似度 Score**（如 `Score: 0.871`），三位小数，tooltip 明确写着"不是准确率或可信概率"——不再让人误以为高分等于"对"。
- 新增「相关度最高」排序：存在语义分数时默认启用，严格按分数降序，无分数的关键词命中排在最后；切换排序不会丢失 HIT 与 Score。
- **关键词筛选与 AI 检索彻底分开**：输入框始终是实时关键词筛选，只有按 `Enter` 或点击搜索框的 ✨ 才发起 AI 语义检索。状态条会明确显示当前处于 `关键词筛选` / `AI 语义检索中` / `AI 语义结果 (N 个)`，内容区还有结果横幅与「清除 AI 结果」。
- 搜索词一改，旧 HIT 与 Score 立即清除；进行中的请求用 token 失效，迟到的结果整体丢弃，不会出现"半新半旧"的混合列表。
- 重复按 `Enter` 或连点 ✨ 不会叠加请求（自动化测试断言只发生一次向量计算）。
- HIT 时间戳不再被写进用户数据文件，重启后不会残留上一次搜索的金色徽章。

### 模型管理：状态、目录、下载、修复都说清楚

- AI 设置新增「语义检索模型 (EmbeddingGemma 2)」区块，状态直白：`已就绪` / `未下载` / `不完整 (n/10 个文件有问题)`，并逐条列出缺失、大小不符、sha256 不符或无法读取的文件。
- 「一键下载 (国内镜像)」与「修复 / 补全下载」共用一条链路：逐文件 sha256 校验，**只补缺失或损坏的部分**，已有的有效文件不会被重写；下载中可取消，进度按文件与总量双行显示。
- 模型目录可自定义（支持"仅使用新路径"或"复制现有模型"两种切换方式，失败会保留旧目录），也可一键恢复默认。
- 一个空目录不会再被误判为"已就绪"——必须清单内全部文件齐全才算可用。

### 关于与检查更新

- 「关于」改为读取**真实打包版本**（v1.1.0 · 构建 3）、仓库地址、许可证入口（内置开源许可清单）与 Releases 页面，删掉了硬编码的 `1.0.1`。
- 新增非侵入式「检查更新」：读取 GitHub 最新**正式** Release，按 SemVer 数值比较（`1.10 > 1.9`，预发布不算更新），只有远端更高时才提示；手动检查失败、404、断网、坏 JSON 都只显示"无法检查"，不会弹错误框。
- 启动时的静默检查最多每 12 小时一次、失败完全静默、不阻塞启动，全程只发一个 GET 请求，不上传媒体、模型或向量数据。
- 不做自我覆盖安装，也不做强制升级——下载与安装始终由用户决定。

## 升级说明

- **数据格式未变**：用户数据库 JSON Schema 与 v1.0.x 完全一致，可直接沿用原有数据库、缩略图与向量缓存。
- **版本号来源**：`pubspec.yaml` 的 `version` 会流到 Windows EXE 的版本资源，「关于」显示的就是它，不会再出现"界面写着 1.0.1、实际装的是别的版本"。
- **Logo 未变更**：本版沿用原有 `app_icon.ico`，新图标仍在候选阶段。

## 发布包内容与首次运行

`video_clip_manager-v1.1.0-windows-x64.zip` 解压后是一个完整目录，运行 `video_clip_manager.exe` 即可：

- 包含 Flutter 运行时、`data/`、Media Kit 播放内核（`libmpv-2.dll`）、ONNX Runtime（`onnxruntime.dll`）、ANGLE / Vulkan / D3D 依赖与各插件 DLL，共 30 个文件。
- **不包含任何 AI 模型权重**，因此包体积只有约 40 MB（解压后约 97 MB）：
  - 视频管理、播放、片段截取、播放列表、关键词筛选**开箱即用**；
  - 「AI 语义搜索」需在 AI 设置里下载 EmbeddingGemma 2（约 530MB，默认落在程序目录 `models/`）；
  - 帧抽取与推理还需要独立的 `local-media-ai.exe` sidecar（放在程序同目录或系统 `PATH`）与 FFmpeg；缺失时不会崩溃，而是给出明确的缺失提示。

## 已知限制

1. **语义检索没有 Top-K 截断**，返回的是全部 `score >= 0.28` 的片段，因此低相关结果也可能出现（这是 v1.0.x 就有的行为，本版只把分数如实显示出来，阈值未调整）。
2. **发布包不含 sidecar 与模型**，纯新环境需要额外获取 `local-media-ai.exe` 与 FFmpeg 才能启用 AI 画面搜索。
3. **更新检查**：仓库现有正式 Release 为 `v1.0.1`，因此 1.1.0 版本上的「检查更新」会正确判定为"已是最新"（远端 1.0.1 不高于本地 1.1.0），不会误报有新版本；发布本版之后同样不会提示。
4. 真实语料的检索相关性评估（`docs/ui-upgrade/semantic_eval/queries.csv`）需在装有模型与 sidecar 的机器上填写，本版未附实测分数分布。
